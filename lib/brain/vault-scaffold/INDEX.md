## Hubs (start here)
_A hub is a NOTE with `type: hub` — a map of content for one active area (a project, a system you own). Create one per area and link every note to at least one._

## Notes
_Atomic facts land here. `PYTHONPATH=<lib> python3 -m brain.search new <slug> --description '…' --type <t>`._

## Docs
